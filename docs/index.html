Enterprise Defense Architecture

The Five Security Invariants

How ProofPilot eliminates the class of prompt-injection and agent-takeover attacks without degrading model autonomous execution.

◈

1. Deterministic Task Contracts

Approved business instructions from CSV or ERP systems are compiled into fixed, cryptographically hashed contracts binding exact request IDs, supplier IDs, allowed fields, and target values. The model cannot alter the contract scope.

◇

2. Mandatory Human Disambiguation

When an ERP search returns multiple matching legal entities (e.g. SUP-2001 vs SUP-2002), autonomous agent selection is strictly prohibited. The system pauses with a 5-minute expiring human sign-off token.

✳

3. Dual-Protocol Model Interface

Integrates natively with Meta muse-wonder-1.0 via the Responses API. Features seamless dual-protocol fallbacks to multimodal vision + strict function calling (propose_action), preventing arbitrary script execution.

🛡

4. OS & Network Sandbox Isolation

Headless browser workers run inside unprivileged Linux Bubblewrap containers (with user, IPC, PID, and network namespace isolation) or in-process Chromium network-abort routing on macOS. API keys are purged with --clearenv.

↗

5. Independent Read-Back Verifier

Portal commits enter an unverified holding state. A separate, read-only verifier principal issues an out-of-band HTTP GET request to verify value parity, version increment, and confirm restricted field SHA-256 hashes are untouched.

📦

6. Signed Evidence Packages

Every execution produces an auditable, point-in-time evidence bundle (JSON, HTML, and ZIP) containing full DOM action logs, screenshot hashes, HMAC capability receipts, and model provenance disclosures.
